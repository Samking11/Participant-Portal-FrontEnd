# Participant Bank Login Demo

This Angular frontend demonstrates a centered Bootstrap login form with
client-side credential validation.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200/`. The demo credentials are `admin` /
`Admin@123`. This is a static frontend exercise and does not authenticate
against the backend.

## Build

```bash
npm run build
```

## Test

```bash
npm test
```
